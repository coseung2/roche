# Vendored assets

`lucide-icons.ttf` is a subset of the Lucide icon font (ISC license,
https://lucide.dev/license) taken from `lucide-static` 1.27.0. It contains
`activity` (U+E038), `chevron-down` (U+E06D), `chevron-left` (U+E06E),
`chevron-right` (U+E06F), `chevron-up` (U+E070), `folder` (U+E0D7),
`folder-plus` (U+E0D9), `refresh-cw` (U+E145), and `gauge` (U+E1BF), used by
the chat model-catalog popover and the workspace/quota sidebar.
